# Shawky Bites

Full-stack food-ordering application built as an earlier MEAN-stack project.

> [!NOTE]
> This repository represents an earlier learning project. It is preserved to show full-stack fundamentals, while newer work such as Requra.AI, Smart Queue System, ACLyze AI, and Jahiz Analytics better represents my current engineering level.

## Overview

Shawky Bites demonstrates a traditional e-commerce and ordering flow with an Angular frontend, Node.js and Express API, and MongoDB persistence.

## Implemented capabilities

- Product and food-item CRUD operations
- Authentication and protected Angular routes
- Shopping cart and ordering flow
- Delivery-location selection through map integration
- Payment-flow integration experiments
- Responsive layouts for common device sizes
- REST API communication between frontend and backend

## Technology stack

| Layer | Technology |
| --- | --- |
| Frontend | Angular, TypeScript, HTML, CSS |
| Backend | Node.js, Express.js |
| Database | MongoDB and Mongoose |
| Authentication | JWT-based application flow |
| Integrations | Maps and payment-provider experiments |

## Running locally

```bash
git clone https://github.com/shawky2002020/Shawky-Bites.git
cd Shawky-Bites
npm install
```

Review the frontend and backend folders for their specific environment variables and start commands.

Do not commit API keys, database credentials, or payment-provider secrets.

## Demo status

This project does not have guaranteed continuously funded hosting. Any previously deployed frontend, API, or database may sleep, expire, or become temporarily unavailable because it used free-tier infrastructure.

The reliable evaluation path is to inspect the source and run the application locally with configured environment variables.
